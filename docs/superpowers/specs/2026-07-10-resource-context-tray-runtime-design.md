# 资源留存、图片上下文与托盘运行状态设计

## 目标

机器人以“收集可复用资源，方便以后照抄”为核心，不分析群友在讨论什么。链接、群文件、图片上下文、日报和托盘运行状态是相互独立的功能。

## 本地资源库

### 链接

- 所有链接先保存原始记录，再生成去重后的本地资源视图。
- 按规范化 URL 全局去重；去除跟踪参数和无意义尾部斜杠。
- 仅过滤明确属于娱乐、广告、拉新、短视频泛分享的链接；无法判断时保留。
- 简介只根据发送消息、引用消息和附近上下文生成一句用途说明。
- 上下文没有说明用途时仍保留，简介显示“群聊未说明用途”。
- 本地资源页显示链接和一句简介，不要求显示来源群。

### 群文件

- 不下载群文件，只保存文件名、大小、类型、群、发送者、时间和 NapCat 提供的位置或标识。
- 按“文件名（不区分大小写）+ 大小 + 类型”去重。
- 同一文件出现在多个群时，保留所有出现记录，聚合视图合并展示其所在群。

### 已有历史数据

- 不重新抓取或重新调用 AI 处理全部历史。
- 对数据库里已经保存、已经处理的链接和文件记录，按新规则重建本地视图。
- 已有原始记录继续保留；只调整去重、筛选、简介和展示。
- 暂不处理 HTML 格式重构。

## 资源日报

- 日报是独立功能，按时私聊发送给配置中的白名单用户，不属于 AI 图片上下文。
- 文件项只显示“文件名 + 群”。
- 链接项只显示“链接 + 一句简介”，不显示来源群。
- 日报对文件和链接分别去重。
- 当天没有新增有效资源时，仍发送“今日无新增资源”，并记录当天已发送，避免重复发送。
- 日报只读取本地资源记录，不下载文件、不读取网页内容。

## AI 图片上下文

- 目标是为没有原图元数据的已保存图片寻找可照抄的信息，不总结群聊主题。
- 只保留与目标图片可关联的提示词、负面提示词、模型、LoRA、工作流、节点、采样器、步数、CFG、种子、放大和重绘参数。
- 图片上下文以图片消息及其附近消息、回复关系为证据，不以固定消息批次的“聊天总结”为目标。
- 没有找到可复用信息时，不生成摘要页面，不显示“最近没有足够相关的聊天记录可总结”，只推进处理游标以避免重复付费。
- 不设置人工复核或待复核状态。
- 原始消息和图片出现记录继续保留。

## 图片去重

- 图片下载后按文件内容 SHA-256 去重，磁盘只保留一份相同内容。
- 同一图片的每次消息出现仍保存记录，以关联不同群、消息和附近上下文。

## 历史消息补拉

- 保留启动时后台补拉，不阻塞实时消息。
- 采用每群历史游标，从最新消息向前追赶，遇到上次已知最新消息即停止。
- 消息按“群 + 消息 ID”去重。
- 该机制用于补齐短期离线期间的消息；不以每次扫描大量历史为正常工作方式。
- 保留管理员 `@全体成员` 清群/保活关键词响应功能。

## Windows 托盘

- 托盘图标不能只代表托盘进程存在，必须反映服务实际状态。
- 菜单显示 NapCat、NapCat 登录 QQ（昵称和完整 QQ 号）、OneBot WebSocket 和 bot 状态。
- 提供打开 NapCat WebUI、打开本地资源页、打开日志、启动/检查、重启、停止全部和仅退出托盘。
- 托盘定时检查服务；NapCat 或 bot 意外退出时自动拉起，并设置冷却时间避免快速重启循环。
- 用户主动停止后暂停自动拉起，直到再次选择启动或重启。
- 再次点击桌面快捷方式时，即使托盘已经存在，也要触发一次启动/状态检查，而不是静默退出。
- “停止全部并退出”等待 NapCat 和 bot 停止后再退出；“仅退出托盘”保留服务运行。

## 非目标

- 不下载群文件。
- 不抓取链接网页正文。
- 不深度解析文件内容。
- 不总结群友在聊什么。
- 不上传本地数据。
- 本阶段不重做 HTML 视觉样式。

## 验证

- 单元测试覆盖链接和文件去重、保守过滤、空日报、图片上下文空结果和历史游标。
- PowerShell 测试覆盖状态菜单、WebUI 入口、主动停止标志、自动恢复和二次快捷方式启动信号。
- 全量测试、Python 编译和 PowerShell 语法检查必须通过。
- 手动验证托盘能显示真实状态，NapCat 和 bot 意外退出后可恢复，主动停止后不会自动启动。
