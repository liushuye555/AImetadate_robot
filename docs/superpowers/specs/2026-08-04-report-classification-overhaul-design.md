# 报告分类重构：03 提示词绑定 + 01 同批折叠 + 性能限制（设计文档）

日期：2026-08-04
关联：子项目 1 见 `2026-08-04-keep-restored-only-mask-design.md`（只留还原图 + 报告遮罩开关）。
本文档覆盖 03_AI上下文 重构、01_AI元数据 同批折叠、以及配套性能限制。

## 背景与目标

现状 03_AI上下文 由"附近 8 条消息命中 AI 关键词"启发式收录，误入率高
（抽样 200 张：仅 40% 含提示词字样、32% 为技术闲聊、28% 与 AI 无关）。
用户期望 03 变成**图片 ↔ 提示词绑定**，而非关键词海捞。同时 01_AI元数据
同批（同一 prompt/工作流）产出的多张图默认折叠展示，并保证数据增长时
匹配/报告不显著变慢。

## 现状

- `images.text_excerpt`：ComfyUI prompt/workflow JSON 前 500 字符（截断）。
- `images.metadata_keys_json`：元数据键列表（如 ["prompt","workflow"]）。
- `messages`：`message_key`（QQ 消息 id）唯一索引；`reply_to_message_id()`
  可解析引用段的 id；`recent_records` 已能解析被引用原文。
- 03 现无绑定结构，报告为批量摘要（`ai_context_batches`）。

## 设计

### 1. 03_AI上下文 拆分两个区

**提示词绑定区（优先）**
- 收录：图片到达时，存在"提示词消息"可绑定（见下方绑定来源）。
- 报告：图片 ↔ 提示词成对卡片展示；**有提示词的图只进此区**，
  不同时出现在参数/模型讨论区。

**参数/模型讨论区**
- 收录：无提示词，但附近文本命中参数/模型关键词
  （ckpt/sampler/denoise/steps/seed/lora/模型名/显卡/出图/炼丹 等）。
- 判定模式可切换（配置项 `images.ai_discussion_judge`）：
  - `rule`（默认）：关键词判定，零模型调用；
  - `llm`：候选交给 DeepSeek 复核"是否确实在讨论 AI/该图"；
  - `both`：规则先筛，LLM 复核。
  - LLM 模式记录每次调用 token 与预估成本，供用户测试对比。

**都不满足 → 04 候选待观察**（TTL 用现有 `images.candidate_ttl_hours`，
面板"候选图片保留时间"默认 24h 可调）。

**LLM 批次摘要停用**：不再生成 `ai_context_batches` 摘要，报告"批次/可复用参数"
区移除；`ai_context_loop` 停用（保留代码，配置默认关闭）。

### 2. 绑定来源

- **时序绑定**：图片之前 **最近 6 条消息 且 4 小时内** 存在提示词消息 →
  绑定到最后一条提示词消息。
  - 提示词消息识别：`/绘图 文生图/图生图` 指令、逗号分隔的 booru tag 行、
    `prompt:`/`prompt{` 块。
- **引用绑定**：① 图片消息引用含提示词的文本 → 绑定被引用文本；
  ② 文本消息引用某张图且含提示词/AI 信号 → 给该图绑定该文本。
  引用按 `message_key` 索引直查，不受时间窗口限制。

### 3. 01_AI元数据 同批折叠

- 新增 `images.prompt_key TEXT` 列：入库时对 `text_excerpt`（500 字符 prompt
  前缀）做 sha1 哈希写入；建索引。
- 报告 01 图库页：`prompt_key` 相同 = 同一批，默认折叠为一张卡片（显示
  首图 + "同批 N 张"），可展开；`index.html` 加"同批折叠"独立开关
  （默认开，localStorage，与遮罩开关同页）。

### 4. 性能限制

- 时序绑定窗口固定（6 条消息 + 4 小时），不看全量历史。
- 引用绑定走 `message_key` 索引 O(1)。
- `prompt_key` 索引支撑同批分组。
- 报告图库页**分页**：每类默认只渲染最新 200 张/页，翻页加载，
  `build_view` 重建时间不随总量线性暴涨。
- LLM 判定按批处理，每轮上限 50 张候选，token/成本入日志。

### 5. 错误处理

- 提示词解析失败/绑定冲突 → 该图按"无提示词"走参数区/04 判定。
- LLM 调用失败 → 回退 `rule` 结果，不阻塞流程。
- 迁移 `prompt_key`：存量 01 图按现有 `text_excerpt` 回填（O(n)，一次性；
  新图入库即写）。

### 6. 测试

- 时序绑定：6 条窗口、4 小时边界、提示词消息识别。
- 引用绑定：图片引用文本、文本引用图片。
- 分区归属：有提示词只进提示词区；无提示词命中参数 → 参数区；其余 → 04。
- 判定模式切换与 LLM 失败回退。
- prompt_key 回填与同批折叠标记。
- 分页渲染边界（≤200/页）。
- 全量 pytest 保持通过。

## 明确不做

- 面板新增 TTL 设置（复用现有 `candidate_ttl_hours`）。
- 纯文本 AI 讨论存档（情况 3 不存）。
- 归档预算/磁盘策略改动。
- 遮罩（见子项目 1 规格）。

## 交付物

- `store.py`：`prompt_key` 列 + 索引 + 回填。
- `collection.py`：提示词消息识别、时序/引用绑定、分区归属、prompt_key 写入。
- `ai_context_analyze.py` / `context_view.py`：批次摘要停用、报告区调整。
- `build_image_view.py`：两区渲染、同批折叠、分页、开关（index.html）。
- 配置：`images.ai_discussion_judge`（rule/llm/both）+ LLM 成本日志。
