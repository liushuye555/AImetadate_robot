# 上下文展示、分析时段与 Windows 托盘改进设计

## 目标

解决以下问题：

- 不替用户预设固定分析时段，同时提供多种方便的调整方式。
- 上下文摘要不再出现“已接收、已过滤”等处理过程套话。
- `03_AI上下文/index.html` 不再一次加载数千条图片和摘要。
- NapCat 完整迁入项目目录，不再依赖外部固定路径。
- 启动不再打开 `.env`，托盘启动与退出行为明确。
- 完成后建立可回溯的 Git 基线。

## 分析时段

### 配置格式

`config.yaml` 是唯一配置源：

```yaml
ai_context:
  allowed_windows: []
```

空列表表示全天允许。多时段示例：

```yaml
ai_context:
  allowed_windows:
    - "00:30-08:30"
    - "12:00-13:00"
```

支持跨午夜时段，如 `23:00-07:00`。时间使用本机时区，格式严格为 `HH:MM-HH:MM`。

### 调整入口

三种入口写入同一字段：

1. 托盘菜单“设置分析时段”打开 Windows 原生设置窗口，可添加、删除、保存多个时段，也可切换全天允许。
2. 用户可以直接编辑 `config.yaml`。
3. 白名单用户可通过 QQ 私聊发送：
   - `分析时段 查看`
   - `分析时段 设置 00:30-08:30,12:00-13:00`
   - `分析时段 全天`

配置修改指令禁止在群聊执行。现有带 `/` 的命令继续兼容，但文档、菜单和机器人提示统一展示无 `/` 格式。

### 生效方式

分析循环每次检查前重新读取 `config.yaml`。托盘、手动编辑和 QQ 指令保存后均无需重启，最迟在下一次检查周期生效。

无效格式不写入配置，并向托盘窗口或 QQ 用户返回具体错误。多个时段允许相邻或重叠，判断时任一时段命中即可。

## 摘要输出

LLM 提示词继续要求 Markdown 结构，并明确禁止：

- “好的，已接收并分析”之类客套话。
- 过滤规则复述。
- 消息数量和处理过程说明。
- 仅输出“无有效 AI 绘图讨论”。

程序端进行第二层清理：当输出中存在 Markdown 标题时，删除第一个标题之前的全部内容。摘要正文仍统一执行 API Key、Token 和密码脱敏。

## 上下文页面

不采用数字分页。页面拆分为：

- `03_AI上下文/index.html`：固定左右布局。
- 左侧目录：按“群 → 日期 → 摘要批次”折叠。
- 右侧内容：通过本地 `iframe` 打开单个批次页面。
- 每个批次页面：只包含该批摘要、消息范围、模型信息和相关图片。

每个批次独立生成 HTML，因此首页不会嵌入全部图片和摘要。`file://` 直接打开即可工作，不依赖本地 HTTP 服务或外部 JavaScript 库。

新图片使用 `message_db_id` 精确关联摘要批次。缺少该字段的旧图片按群和本地日期归入对应日期的“历史未精确关联图片”页面，避免错误绑定到最新摘要。

## NapCat 内迁

迁移步骤：

1. 停止机器人及 NapCat 相关进程。
2. 确认源目录为 `D:\Hermes\Data\tools\napcat\NapCat.Shell.Windows.Node`。
3. 移动整个目录到项目内 `runtime\NapCat.Shell.Windows.Node`。
4. 验证目标目录存在 `napcat.bat`，源目录已不存在。
5. 将 `runtime/` 加入 `.gitignore`，不提交约 334MB 的运行程序和数据。

启动脚本默认使用项目内路径。`launcher.config.ps1` 仅作为可选覆盖，不再是必需依赖。

## 启动、环境变量与退出

托盘快捷方式启动后：

1. 如果 NapCat 未运行，则启动 NapCat。
2. 等待 OneBot WebSocket 端口可用。
3. 如果机器人未运行，则启动机器人。

移除所有 `call .env`。Python 代码已经自行读取 `.env`，Windows `cmd` 对无扩展执行脚本的处理会触发文件关联，因此此前可能打开编辑器。

托盘菜单提供：

- `停止全部并退出`：主要退出操作，停止机器人和 NapCat 后关闭托盘。
- `仅退出托盘（保持后台运行）`：只关闭托盘图标。
- `停止机器人和 NapCat`：停止服务但保留托盘。
- `启动 / 检查运行状态`、打开页面、打开日志、设置分析时段。

## 测试与验证

新增或更新测试覆盖：

- 默认 `allowed_windows == []`。
- 多时段、跨午夜和无效格式。
- QQ 私聊查看、设置、全天命令以及群聊拒绝。
- 修改配置后分析循环能够重新加载。
- 摘要清理删除第一个 Markdown 标题之前的全部套话。
- 上下文首页不包含全部批次正文，目录链接能打开独立批次页面。
- 旧图片进入历史未精确关联页面。
- 启动脚本不再包含 `call .env`。
- 启停脚本默认引用项目内 NapCat 路径。
