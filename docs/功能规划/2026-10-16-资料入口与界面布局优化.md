# 资料入口与界面布局优化

本轮按“查看资料 → 搜索筛选 → 展开依据 → 调整采集设置”的操作顺序整理界面。

## 管理器

侧栏“报告”改为“资料中心”。页面优先提供群知识、待跟进、术语、群总结、精选保留文件五个入口；图片总览、全部采集的群文件、资源链接作为其他资料入口。图片分类、更新与备份、日报预览放在次级区域。保留文件和全部群文件使用不同名称，避免混淆。

“待跟进”直接打开知识报告的对应队列。修复了本地文件链接中的 `#followup` 被当作文件名的问题；资料页尚未生成时，先从已有本地记录生成页面再打开，不调用 AI，不启用采集功能。“更新资料页面”现在同时更新知识、术语、总结和保留文件页面。

采集页分为“群知识 / 采集范围 / 高级规则”，默认打开群知识。群知识编辑窗口再分为“基础设置 / 内容与保留 / AI高级设置”，每页独立滚动，确定、取消及页面底部保存区域始终保留。编辑后显示“有未保存的更改”；未选择群时禁用编辑和移除，避免无反馈的点击。原有未知配置字段继续保留，功能仍需主动开启。

本地进程无法启动时会回报失败，避免资料入口持续停在“正在准备”。

## 网页报告

- 顶部统一显示知识、术语、总结和保留文件导航。
- 知识页以四个按钮切换知识、待跟进、已归档和全部；数字展示本页各队列总量。
- 搜索框放在首位，群组、主题为常用筛选，资料类型和价值收进“更多筛选”。“清除筛选”保留当前队列。
- 每页显示 20 项。切换筛选重置页码，浏览器返回可恢复队列，`Ctrl/Cmd + K` 聚焦搜索。
- 卡片先显示摘要，再按需展开完整内容、缺少信息、进展和原消息；术语释义与依据也分层显示。
- 摘要先完整脱敏再截断，防止截断破坏密钥识别。所有资源本地加载。
- 空状态给出下一步操作，窄屏下筛选和导航换行；桌面搜索栏固定时，翻页保留首条内容的可见空间。

正在查看的网络攻防群历史报告已使用新布局重新生成。141 个话题、189 条资料、75 条释义的内容与数量未因界面调整改变；快照时间和审计说明收进可展开区域。

## 验证

Python 全套 877 项通过；新增交互测试覆盖队列深链接、浏览器返回、搜索、分页、清除筛选和摘要脱敏。Qt 资料入口、群知识设置、通用设置、配置桥共 36 项通过（含初始化与清理），管理器已重新构建。原生 Qt 组件在 660×560 窗口下进行了滚动与入口可见性检查，并保存了测试实例截图。

浏览器工具禁止读取本地 `file://` 页面，因此网页部分采用生成文件检查和实际执行页面脚本验证，未进行浏览器截图验收。

本轮只在原有未提交的 main.cpp 和测试 CMakeLists.txt 中加入必要接线与测试目标；提交时只纳入这些新增部分。原有主题、图标及其他界面改动保持在工作区。
