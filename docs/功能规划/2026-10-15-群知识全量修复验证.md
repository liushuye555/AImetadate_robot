# 群知识全量修复验证（2026-10-15）

本轮针对 Deepseek网络攻防技术交流9群，在独立目录 `data/knowledge-optimized-20261015` 使用真实 AI 重放历史。正式配置未修改，功能仍需主动开启；没有发送群消息，也没有下载群文件。

## 修复内容

- 将知识价值判断与事实验证状态分开保存。方法与亲测结果要有原文支持的具体条件、操作和结果摘录，才允许保留 high；工具自述、观点、求助、服务状态和未验证资源不据此升级。缺少质量字段保留为候选。
- 话题关联缺少明确判断时，增加独立 AI 判断阶段；只允许关联本群给定候选。不同成员的独立问题没有引用承接时保守拆开，公共服务公告允许跨成员续更。保留原关联理由，便于复查。
- 术语与知识继续独立。术语页按同群同名词条聚合，多种含义各自保留证据、推断与状态；搜索和状态筛选必须落在同一个释义上，不让其他含义误命中。
- 修复多阶段用量结算、失败重试复用、缓存文件预览恢复，以及先脱敏再编码 JSON，避免重复调用、预览证据丢失和 JSON 转义损坏。

## 验证与边界

项目虚拟环境全套测试：805 passed。现有 Pillow 弃用提示 16 条。独立代码审查发现的公共服务公告拆分问题已修复，增加 question → transient 回归用例。全量 HTML 的本地链接存在性和卡片数量检查通过：134 个话题卡、97 个术语卡、38 批摘要。

浏览器工具的 URL 策略拒绝打开本地 file 页面，因此本轮没有完成浏览器截图或人工布局验收；没有绕过该限制。上述 HTML 检查和筛选行为测试不等同于视觉验收。

覆盖检查只验证消息范围与引用完整性，不证明模型语义结论正确。图片未做视觉识别，外链未联网核实，文件正文预览与保留在本次回放中关闭。原文片段存在也不代表推断正确；仍应保留人工确认入口。建议后续先用人工标注的小样本评估漏收和误收，再决定是否调整高价值门槛。
