# 外部依赖

## 项目外文件

运行时唯一必须位于项目目录之外的文件是 NapCat：

- NapCat 安装目录，其中需要存在 `napcat.bat`。
- 本机路径写入 `scripts/windows/launcher.config.ps1`，该文件不会提交到 Git。

项目本身不依赖其他散落在外部目录的模板、提示词或静态资源。

## 项目内运行数据

以下内容都位于项目内，但属于本机运行状态，不进入 Git：

- `.env`：LLM 地址和密钥。
- `config.yaml`：QQ 白名单、黑名单和本机配置。
- `data/bot.db`：SQLite 主数据库。
- `data/images/`：图片归档和候选缓存。
- `data/view/`：可重建的本地 HTML 页面。
- `logs/`、`run/`：日志和 PID 文件。

## 软件与网络依赖

- Python 3.11+ 与 `uv`。
- Python 包：`websockets`、`PyYAML`。
- NapCat / OneBot v11 正向 WebSocket。
- 配置的 OpenAI 兼容 LLM API。
