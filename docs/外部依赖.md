# 外部依赖

## 项目外文件

项目不再依赖散落在项目外的运行文件、模板、提示词或静态资源。NapCat 放在项目内 `runtime/NapCat.Shell.Windows.Node`，其中需要存在 `napcat.bat`；整个 `runtime/` 不进入 Git。

如需使用其他 NapCat 安装位置，可通过 `NAPCAT_DIR` 环境变量或不进入 Git 的 `scripts/windows/launcher.config.ps1` 覆盖。

## 项目内运行数据

以下内容都位于项目内，但属于本机运行状态，不进入 Git：

- `.env`：LLM 地址和密钥。
- `config.yaml`：QQ 白名单、黑名单和本机配置。
- `data/bot.db`：SQLite 主数据库。
- `data/images/`：图片归档和候选缓存。
- `data/view/`：可重建的本地 HTML 页面。
- `logs/`、`run/`：日志和 PID 文件。
- `runtime/`：NapCat 程序和运行数据。

## 软件与网络依赖

- Python 3.11+ 与 `uv`。
- Python 包：`websockets`、`PyYAML`。
- NapCat / OneBot v11 正向 WebSocket。
- 配置的 OpenAI 兼容 LLM API。
