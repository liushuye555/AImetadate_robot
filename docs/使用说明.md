## 4. 配置

主配置：

```text
config.yaml
```

关键配置说明：

```yaml
onebot:
  ws_url: "ws://127.0.0.1:3001"

listen:
  blocked_groups:
    - "不采集的群号"

reply:
  require_at_in_group: true
  allow_group_admins: true
  whitelist_users:
    - "允许私聊和触发回复的QQ号"
  whitelist_groups: []

storage:
  data_dir: "data"

startup_history:
  enabled: true
  mode: blacklist
  all: true
  max_pages: 200
  count: 50

ai_context:
  enabled: true
  provider: ds_v4_flash
  scopes: all_groups
  chunk_size: 200
  auto_interval_minutes: 15
  min_new_messages: 300
```

DeepSeek 配置放在 `.env`：

```text
DS_V4_FLASH_BASE_URL
DS_V4_FLASH_API_KEY
DS_V4_FLASH_MODEL
```

## 5. 启动与停止

### 后台启动 NapCat 与 bot

推荐先安装托盘快捷方式：


NapCat 安装目录写在 `scripts/windows/launcher.config.ps1`。该本机配置由 `launcher.config.ps1.example` 复制而来，不进入 Git。

不使用托盘时仍可直接运行：



## 7. 数据与页面

### 数据库

```text
data/bot.db
```

主要表：

- `messages`：消息正文、用户、群、原始事件、去重键。
- `links`：链接及分类信息。
- `files`：模型、压缩包、工作流文件元信息。
- `images`：图片元数据、保存路径、保留原因。
- `ai_context_batches`：DS V4 Flash 分批摘要。
- `daily_reports`：已发送日报。
- `history_cursors`：历史补拉游标。

### 图片目录

```text
data/images/ai/             长期归档，不作为缓存删除
data/images/candidates/     临时候选，可按 TTL 清理
```


打开：

包含：

## 8. 手动刷新本地页面

```bash

```

该操作会从数据库全量重建 HTML 页面，不删除数据库旧记录，也不删除长期图片归档。

## 9. 日报

日报开头包含新增文件数、链接数、来源群数量和重点简介；链接与文件条目也会附带简短用途说明。报告和本地页面会对常见 API Key、Bearer Token 做脱敏。

上下文分析可以避开高价时段。例如：

```yaml
ai_context:
  min_new_messages: 300
  allowed_windows:
    - "00:30-08:30"
```

消息会持续记录并累计，只有同时满足消息阈值且进入允许时间窗口时才调用 LLM。`allowed_windows: []` 表示全天允许，支持 `"23:00-07:00"` 这种跨午夜窗口。

- 默认在本地时间 20:00–21:00 检查。
- 只统计上次日报发送后的新增资源。
- 链接与文件均去重。
- 按群名分类。
- 文件只写类型、文件名、大小，不附长 URL。
- 明显快手/抖音营销分享会过滤。
- 内容过长时分段发送。

## 11. 常见问题

### bot 在线但不回复

1. 确认端口：`127.0.0.1:3001`。
2. 确认 QQ 号在 `reply.whitelist_users`。
3. 群聊确认已直接 `@机器人`。
4. 查看 `logs/bot.log` 中的 `reply_send`。
5. 检查 `run/bot.pid` 对应进程是否存在。

### 本地页面没有更新

运行：

```bash
uv run python -m qq_onebot_whitelist.maintenance --project-dir .
```

### 图片页面打不开

用浏览器打开 `file:///.../data/view/index.html`，不要直接依赖目录索引。文件名中的 `#` 已由生成器 URL encode。

### DeepSeek 没有消耗

- 自动分析每 15 分钟检查。
- 累计新增消息达到 300 条才触发。
- 查看 `ai_context_batches` 和 `logs/bot.log`。
