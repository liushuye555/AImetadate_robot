# 互联网背景与谐音指代

这份背景层帮助 AI 理解平台、常用概念、谐音与缩写。它与本群聊天记录、群知识和术语表分别保存，只辅助理解和检索分类，不证明某次操作成功，也不补造未给出的供应商、价格或地区限制。

可维护词典位于 `qq_onebot_whitelist/knowledge_background.json`。首版包含 16 组条目，记录版本、更新时间、定义层级、别名状态、适用语境、歧义、参考来源和禁止推断的边界。

## 三层依据

1. **通用背景**：闲鱼是二手交易平台；虚拟卡、Visa、发卡机构与开卡渠道是不同概念；API、客户端和代理分别描述接口、交互入口与转发路径。
2. **本群确认**：使用本群人工确认的对象目录、别名和用途。例如富江、无限各代在指定群中被确认归为破甲工具。本群确认优先，不能全局套用到其他群。
3. **候选解释**：梯子、魔法、号、料、车、五代等保留多个可能含义。根据原消息、引用和上下文判断；条件不足时保留对象未知，同时尽量归入有依据的通用资料主题。

关闭术语学习不会阻止已启用的知识整理使用这份通用阅读背景；它不会自动启用术语学习或生成术语条目。未启用知识整理时也不会因此调用 AI 或访问互联网。

## 谐音与语境

“咸鱼”在账号交易、二手买卖、价格等语境中，可以作为“闲鱼”的候选写法；“咸鱼好吃”不会自动归到闲鱼平台。“海鲜市场”同样需要交易语境。候选写法不会直接成为群内已确认词义。

“虚拟visa卡”可以归入“虚拟卡”资料主题，即使具体发卡平台未知。“国内号”可以支持账号交易或账号主题，但不能推断是哪家平台账号。“五代”不能据相似叫法自动并入某个工具家族。

对象主题与资料标签分别整理：一条资料可以同时关联“闲鱼”（平台对象）、“账号交易”“钓鱼与账号安全”（资料主题）；风险、价格与使用经历仍保留群友归因和验证状态。

## 更新与复核

知识整理只读取本地词典，不会自动联网寻找黑话释义。增加背景条目时，应记录来源、歧义与使用条件；没有稳定依据的含义使用 candidate。新词典内容参与分析缓存标识，避免沿用旧解释。AI 输出的资料主题仍须引用当前条目的精确原文，背景说明不能充当证据。

词典变更后，可在对应群已明确启用知识提取的前提下复核已有资料：

```powershell
.venv/Scripts/python.exe -m qq_onebot_whitelist.knowledge organize-tags --group 338431075 --batch-size 5 --max-batches 40
```

此命令会重新检查旧版标为“已复核但无分类”的条目，使用当前主供应商、遵守群预算，备份后更新对象和资料主题元数据。无法分类时保留原因；不改写原正文、不合并不同人的经历、不改变解决状态。
