占位图标说明
============

这里所有 SVG 都是占位图标，直接用同名文件替换即可换肤，无需改代码：
- nav-*.svg      左侧导航图标（24x24，线性风格，浅色描边 #cdd8ec）
- card-*.svg     概览页状态卡图标（28x28，描边 #7aa5ff）
- app.svg        应用/托盘图标（64x64）
- mascot.svg     侧栏底部看板娘占位（建议透明底立绘，宽约 176）

替换建议：保持文件名不变、覆盖文件内容即可；导航图标建议用
单色线性风格（浅色描边），在深色侧边栏上显示效果最好。
修改图标后需要重新构建（qrc 资源编译进 exe）。
